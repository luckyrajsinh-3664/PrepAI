# PrepAI - Agile Product Backlog & Sprint Artifacts

## User Stories

### Epics: User Authentication & Multi-Domain Preparation
1. **US-01 (Authentication):** As a user, I want to securely register and log in using encrypted passwords and JWT tokens so that my practice progress remains private.
2. **US-02 (Role Filtering):** As a job candidate, I want to select my specific target role (e.g., UPSC Civil Services, AI/ML Engineer) so that I receive tailored interview questions.
3. **US-03 (AI Evaluation):** As an interviewee, I want real-time semantic scoring and feedback on my answers so that I can identify technical and communication gaps.
4. **US-04 (ATS Resume Analysis):** As an applicant, I want to upload my PDF resume to compare it against market roles and view missing competencies.

## Sprint Breakdown (7 Weeks)

* **Sprint 1 (Weeks 1–2): Requirement Gathering & Glassmorphic UI Setup**

* **Sprint 2 (Weeks 3–4): NoSQL Database & REST API Architecture**

* **Sprint 3 (Weeks 5–6): Integration & Cloud CD Pipeline**

* **Sprint 4 (Week 7): Automated CI Pipeline & Verification**
